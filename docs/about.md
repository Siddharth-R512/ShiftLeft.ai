### The real QA Workflow:

**Inputs QA receives:**
- BRD/ FRD (Word/PDF)
- Jira user stories
- Acceptance criteria (Often vague)
- Occasionally API Specs (swagger)
- Sometimes nothing with screenshots

**Outputs QA must produce:**
- Test Scenarios
- Test Cases
- Test Scripts (manual/automation)
- Regresison suites
- Coverage reports

**Gaps (THE REALITY)**
| Step | What actually happens |
| --- | --- |
| Requirements | Ambiguous, late, changing |
| Test Design | Copy-paste, human bias |
| Edge Cases | Missed |
| Traceability | AManual & painful |
| Maintenance | Extremely costly |
| Feedback Loop | Weak / delayed |
